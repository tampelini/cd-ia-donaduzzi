# Logos das empresas

Esta pasta guarda os logos que aparecem na seção **"O que você vai fazer, e onde"** da aba Início.

Como usar:

1. Coloque aqui só logos com **autorização por escrito** da empresa, usando o arquivo oficial do manual de marca.
2. Salve com **exatamente** o nome indicado abaixo, em `.svg` (preferível) ou `.png` (fundo transparente, mínimo 200×200 px).
3. Envie o arquivo para esta pasta (`assets/logos/`) pelo GitHub (Add file → Upload files). Em 2 a 3 minutos o site é publicado de novo sozinho e passa a mostrar o logo no lugar das iniciais, sem mexer no código.
4. Empresa sem arquivo continua aparecendo com o selo de iniciais.
